## 使用说明

感谢使用本插件！以下是功能指南：

- 状态栏点击：点击底部状态栏可访问帮助页面。
- Alt+p :将复制的devtool元素转换成DrissionPage定位表达式。
- 编辑器里输入 **dp-**  可以触发DrissionPage代码模板提示。
- 编辑器里输入 右键菜单 可粘贴各种DrissionPage代码模板。
